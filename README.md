## PAYROLL MANAGEMENT SYSTEM - Using core java

# PROJECT OVERVIEW
## A payroll system manages employee pay information. In this project, you will model 
## two employee types and let one manager class keep track of them

# WHAT PROJECT DOES
## The payroll software as a system organisations use to manage employee salaries and 
## related financial information. This learning project focuses on the core employee 
## records and salary calculation rules.


## Full time employee
## Has a fixed monthly salary supplied when the object is created.

## Part time employee
## Has hours worked and an hourly rate. Pay calculation is calculated from those two values.

## Payroll System
## Stores employee objects and adds, removes and displays them.

## Employee
## Defines information shared by employee, such as name and ID.# Payroll_mgnt_sys
